# CSA02 – C Programming Assignment

## Assignment Overview
This repository contains the C Programming Assignment programs covering **Structures, Pointers, Recursion, Dynamic Memory Allocation, File Handling, and Recursive Function Analysis** using practical Blood Bank Management and inventory-related examples.

## Tasks Included

### Task A – Design and Implementation

| Task | Topic | Description |
|---|---|---|
| Task A1 | Blood Bank Management Using Structures | Implements donor registration, eligibility checking, blood group search, stock management, summary generation, and binary file storage. |
| Task A2 | Design with Recursion | Implements digital root calculation, linear recursive power, and halving recursive power. |
| Task A3 | Design with Pointers | Demonstrates pointer arithmetic, finding the lowest blood stock, and command-line operations for issuing blood units. |
| Task A4 | Dynamic Memory Allocation | Uses `malloc()`, `realloc()`, and `free()` to dynamically store and manage blood donor records. |

### Task B – Implementation and Analysis

| Task | Topic | Description |
|---|---|---|
| Task B1 | Recursive Function Implementation and Instrumentation | Compares linear recursive power and divide-and-conquer recursive power by counting function calls. |
| Task B3 | Text File vs Binary File | Demonstrates binary file record access, updating stock records using `fseek()`, `fread()`, and `fwrite()`. |
| Task B4 | Dynamic Memory Using `realloc()` | Implements a dynamic donor list that automatically doubles its memory capacity when full. |

## Concepts Covered

- Structures and nested data management
- Functions and function arguments
- Recursion and divide-and-conquer techniques
- Pointer arithmetic and pointer operations
- Dynamic memory allocation using `malloc()`, `realloc()`, and `free()`
- File handling using `fopen()`, `fread()`, `fwrite()`, and `fclose()`
- Random access using `fseek()`
- Command-line arguments
- Memory management and function call analysis

## Programming Language
- **Language:** C
- **Compiler:** GCC
- **Header Files:** `stdio.h`, `stdlib.h`, `string.h`

## How to Compile and Run

1. Open the terminal in the task folder.
2. Compile the C program using GCC:

```bash
gcc program.c -o program
```

3. Run the executable:

**Windows:**
```bash
program.exe
```

**Linux:**
```bash
./program
```

Replace `program.c` with the actual source filename.

This assignment provides practical experience in C programming through real-world donor management and stock management examples. It demonstrates important programming concepts, including structures, pointers, recursion, dynamic memory allocation, and file handling.
